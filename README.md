# Светофоры Курьера — MVP

Android-приложение (MVP), которое:
1. Позволяет отметить кнопкой места светофоров на твоём маршруте.
2. В фоне записывает, останавливался ли ты у каждого (красный) или проезжал без остановки (зелёный), с привязкой ко времени суток и дню недели.
3. Показывает плавающее окошко поверх других приложений (в т.ч. поверх Яндекс.Карт) с прогнозом: "зелёный в N% случаев в это время, обычно стоим ~X сек".

Все данные хранятся только на телефоне (файл `lights_data.json` во внутренней памяти приложения), никуда не отправляются.

## Как этим пользоваться после установки
1. Открыть приложение → нажать «Разрешить показ поверх экрана» → в открывшихся настройках включить переключатель для приложения.
2. Дать разрешение на геолокацию (в том числе «Разрешить всегда» / фоновый доступ, когда система спросит).
3. Нажать «Начать запись поездки» перед выездом на маршрут.
4. Проезжая мимо каждого светофора на маршруте (первые несколько поездок), нажимать «Отметить светофор здесь», когда находишься прямо у него (можно попросить пассажира, либо остановившись на секунду в безопасном месте).
5. Дальше — просто езди с включённой записью. Первую-две недели прогноз будет пустым/неточным, это нормально — приложению нужно накопить статистику по каждому светофору и времени суток.
